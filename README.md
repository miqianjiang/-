# 线路保护图纸智能解读（功能2）

当前版本是可本地运行的最小可用原型，包含：

- PDF、PNG、JPG、WEBP 本地上传
- PDF 页面渲染和图纸预览
- 鼠标/触控框选局部区域
- 学生端只展示案例图纸，不直接展示教材正文
- 案例一：CSC-211 开关量输出与跳合闸回路
- 案例二：PSL641U 接点联系图
- 结构化解读结果展示
- 学生端展示识别、作用、关系、逻辑、教师/课本提示、学习引导和安全提示
- 未配置 API Key 时的演示模式
- 配置阿里云百炼 API 后的实时模型调用接口

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:3000`。

## 配置模型

复制 `.env.example` 为 `.env.local`，填写：

- `DASHSCOPE_API_KEY`

API Key 只能保存在 `.env.local`，不要写进前端代码，也不要提交到 Git。

当前案例素材：

- `public/cases/csc211-switch-output.png`：案例一图纸
- `public/cases/psl641u-contact.png`：案例二图纸
- `data/textbook-source.pdf`：老师提供的整本教材，作为后台资料，不在学生端直接展示
- `data/teacher-annotations.docx`：老师提供的图纸注释，作为后台标准注释，不在学生端直接展示

## 学生端来源提示规则

右侧解读结果需要显示一个来源提示，让学生知道这段解释的可靠性来源：

- 如果命中老师提供的图纸注释，显示为 `教师注释`，展开标题为 `教师提示`。
- 如果命中教材或本地案例知识，显示为 `教材内容`，展开标题为 `课本提示`。
- 如果教材中没有直接对应内容，显示为 `AI 补充`，展开标题为 `AI 补充`。
- 学生自行上传未知图纸时，默认走 `AI 补充`，并提示“教材中未检索到直接对应内容”。

当前两张案例的来源逻辑：

- `CSC-211 开关量输出与跳合闸回路`：`教材内容`，因为对应教材图 1-7 及相关说明。
- `PSL641U 接点联系图`：命中老师已注释区域时为 `教师注释`；未命中注释区域时为 `AI 补充`。

当前 PSL641U 已接入的老师注释区域：

- 保护跳闸回路
- 操作开关/控制开关（KK 把手）
- 断路器位置指示灯
- 保护合闸回路

注意：不要恢复旧版“教材依据”列表。学生端只展示自然语言的来源提示和课本提示，不展示后台依据条目。

当前模型链路全部走阿里云百炼：

- `QWEN_OCR_MODEL`：用于识别图中文字、端子号、设备代号
- `QWEN_VISION_MODEL`：用于理解框选区域的图形和连接关系
- `QWEN_EXPLANATION_MODEL`：用于生成面向学生的结构化讲解

## 当前边界

- 首版采用“学生框选局部区域”，尚未实现整图自动标注。
- 当前先以两张案例图纸为学生端训练入口。
- 后台教材尚未做全文检索；当前先接入了人工整理的案例依据卡片和老师图纸注释，依据不直接展示给学生。
- AI 结果只用于教学，必须由专业教师核验。
